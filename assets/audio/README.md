# Committee audio

IPL and Dalal Street use the supplied MP3 files.

To use approved commercial recordings:

1. Place the licensed files in this directory.
2. Set their paths in `LICENSED_AUDIO` near the top of `assets/js/main.js`.
3. Keep proof that the event has both composition and sound-recording/web-use permission.

Suggested filenames:

- `ipl-theme-licensed.mp3` (installed)
- `scam-1992-theme-licensed.mp3` (installed)

The website starts committee themes immediately on selection. IPL begins at 00:00.5 and Dalal Street begins at 00:01; both continue through the supplied recording until the visitor uses the committee Stop Music control, leaves the committee dossier, switches global Sound off, selects another musical committee, or the file ends.
