# Committee audio

Committee sound starts only after a visitor enables the sound control.

- `ipl-theme-licensed.mp3` — IPL page soundtrack
- `scam-1992-theme-licensed.mp3` — Dalal Street page soundtrack
- `mcc-theme.mp3` — user-provided Midnight Crisis soundtrack

The tracks are assigned in `assets/js/boardroom.js` and stop when visitors leave or disable sound. Confirm music rights before publishing these recordings on the public website.
